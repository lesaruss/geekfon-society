Icons required for PWA + app store submission:
- icon-192.png  (192x192) — PWA home screen icon
- icon-512.png  (512x512) — PWA splash + Google Play

Generate from geekfon-logo.png at the repo root (public/geekfon-logo.png).

Apple App Store additionally requires:
- AppIcon.appiconset in the Xcode project (1024x1024 master, Xcode auto-generates sizes)

Use ImageMagick or Figma to export from the source logo.
